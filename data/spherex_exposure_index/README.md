# Listas oficiales de exposiciones SPHEREx · Official SPHEREx exposure lists

**ES.** Cada archivo es la respuesta real de **IRSA SIA** (colecciones `spherex_dr1`, `spherex_dr1_deep`, `spherex_qr3` y `spherex_qr3_deep`) con las exposiciones L2b que cubren uno de los cinco objetivos del reto. La fecha de la consulta está en `query.date_utc`. SkyChrono la usa **solo** si IRSA TAP y SIA no responden, para que el blink multi-época de los objetivos siga funcionando: las imágenes FITS se leen siempre en vivo desde AWS S3 (`s3://nasa-irsa-spherex/`), y aquí no hay imágenes ni datos inventados. Para actualizarlas con IRSA accesible: `python tools/refresh_exposure_index.py`.

**EN.** Each file is the real **IRSA SIA** response (collections `spherex_dr1`, `spherex_dr1_deep`, `spherex_qr3` and `spherex_qr3_deep`) listing the L2b exposures that cover one of the five challenge targets. The query date is in `query.date_utc`. SkyChrono uses it **only** if IRSA TAP and SIA do not respond, so that the multi-epoch blink of the targets keeps working: the FITS images are always read live from AWS S3 (`s3://nasa-irsa-spherex/`), and there are no images or invented data here. To refresh them while IRSA is reachable: `python tools/refresh_exposure_index.py`.
